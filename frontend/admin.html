真实公开数据导入流程

从 TPDC / MODIS / CMA 下载环境数据，叠加工行授信和保险台账 → 转换 → 导入 → 训练模型

步骤 1 — 登录 国家青藏高原科学数据中心，搜索 NDVI、积雪、气象等数据集，下载到 public_data/raw/tpdc/
步骤 2 — 运行转换脚本：
python public_data/scripts/ingest_public_data.py --source tpdc --dataset ndvi --input public_data/raw/tpdc/xxx.csv --output public_data/processed/remote_sensing.csv --table remote_sensing_data
步骤 3 — 在下方"CSV 数据导入"区域，选择对应数据表，上传 public_data/processed/*.csv
步骤 4 — 点击 工行风险评估 中的"重新训练模型"按钮
步骤 5 — 访问 /api/model/evaluation 查看 MAE/RMSE/R2 评估指标
